# Swift / SwiftUI development

- ALWAYS invoke the `swiftui-expert-skill` when writing, reviewing, or
  refactoring any Swift/SwiftUI code — state management and `@Observable`
  data flow, view composition/invalidation, lists & identity, environment,
  animations, Liquid Glass, deprecated-API migration, or Instruments
  analysis. Use it before hand-rolling a solution, not after something breaks.
